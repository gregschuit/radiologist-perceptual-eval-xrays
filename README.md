# Perceptual Evaluation of GANs and Diffusion Models for Generating X-rays

This repository contains the codebase associated with the paper:

**"Perceptual Evaluation of GANs and Diffusion Models for Generating X-rays"**  
Authors: Gregory Schuit, Denis Parra, Cecilia Besa  
Pontifical Catholic University of Chile  
Accepted at the **1st MICCAI Workshop on Human-AI Collaboration (HAIC)**, MICCAI 2025

This paper is based on my master's thesis, which explores the generation of synthetic chest X-rays using adversarial (GAN) and diffusion models. The study focuses on the perceptual evaluation of radiologists to assess the quality and diagnostic utility of the generated images.
